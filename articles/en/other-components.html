Sounds, Selection and Other Components

Sound Source

This setting decides which AudioSource plays the sounds of sound tracks.

Choosing the AudioSource

Set it in code with KeyTween.audioSource. The inspector does not edit this field (it shows only under Raw Data).

  • If it is set, sounds play through that source.
  • If it is empty, sounds play through one shared, hidden 2D AudioSource (PlayOneShot).

You only need to set it when you need a mixer group or 3D sound. Each sound track can also set its own source.

Optional Integrations

When the following libraries are installed, KeyTween gains extra extension methods.

Library Extension methods

R3 PlayAsObservable, EventsAsObservable, EventAsObservable, StateStartedAsObservable, StateCompletedAsObservable, StateCanceledAsObservable

An integration turns on automatically when its library is installed, with nothing to configure. The same methods also take a start time, and work on a With play. For details, see Integrations.
