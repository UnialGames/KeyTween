여러 KeyTween 함께 기다리기

여러 오브젝트의 KeyTween을 동시에 재생하고, 모두 끝날 때까지 기다리는 방법입니다.

모두 시작한 뒤 차례로 기다리기

PlayAsync는 .NET Task가 아니라 Unity Awaitable을 돌려주므로 Task.WhenAll에 바로 넣을 수 없습니다. 대신 재생은 PlayAsync를 부르는 순간 시작됩니다. 전부 먼저 시작해 두고 차례로 기다리면 WhenAll과 같은 결과를 얻습니다.

var plays = anims.Select(a => a.PlayAsync("Hover")).ToList();   // 여기서 모두 동시에 시작합니다
foreach (var play in plays) await play;                         // 모두 끝날 때까지 기다립니다

Task.WhenAll로 기다리기

Task.WhenAll을 쓰려면 각 재생을 Task로 감쌉니다.

static async Task AsTask(Awaitable awaitable) => await awaitable;

await Task.WhenAll(anims.Select(a => AsTask(a.PlayAsync("Hover"))));

UniTask.WhenAll로 기다리기

UniTask를 설치했다면 연동에서 제공하는 PlayUniTaskAsync를 쓸 수 있습니다.

await UniTask.WhenAll(anims.Select(a => a.PlayUniTaskAsync("Hover")));

하나가 취소되면

재생 중 하나라도 취소되면(끝나는 경우) OperationCanceledException이 발생합니다. 예외가 발생하는 위치는 방법마다 다릅니다.

  • 차례로 기다리기: 취소된 재생을 기다리는 await
  • Task.WhenAll, UniTask.WhenAll: WhenAll
