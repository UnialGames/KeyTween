빠른 시작

에디터에서 첫 애니메이션을 만들고, 코드에서 상태를 재생하는 방법을 알아봅니다. 상태란 Hover나 Open처럼 이름이 붙은 애니메이션 하나를 말하며, Prefab의 KeyTween 컴포넌트에 저장됩니다.

1. 에디터에서 호버 연출 만들기

포인터를 올리면 버튼이 1.1배로 커지면서 밝아지고, 포인터를 빼면 원래대로 돌아오게 만듭니다. 코드는 작성하지 않습니다.

다 만들고 나면 KeyTween 창은 아래처럼 보입니다.

  • Hover와 Unhover 상태
  • 버튼의 Scale 트랙과 Color 트랙
  • 오른쪽의 키 인스펙터

  1. 버튼 Prefab을 열고 Window > KeyTween Editor를 엽니다.

  2. Add KeyTween to 'Button' 버튼을 누릅니다. KeyTween 컴포넌트를 직접 추가해도 됩니다.

  3. 상태 탭의 + 버튼을 눌러 상태를 만들고, 상태 인스펙터에서 이름을 Hover로 바꿉니다. 새 상태는 타임라인이 비어 있으며, 상태 인스펙터에는 Name, Loop, Duration, Play On 설정이 나옵니다.

  4. 타임라인의 빈 곳을 우클릭하고 Add Track… 항목을 고릅니다.

  5. RectTransform 아래의 Scale과 Image 아래의 Color를 선택한 뒤 Add 2를 누릅니다. 트랙마다 0초 키와 0.2초 끝 키가 만들어집니다.

  6. Scale 트랙의 끝 키를 클릭하고 Value를 1.1, Ease를 OutBack으로 설정합니다.

  7. Color 트랙의 끝 키를 조금 더 밝은 색으로 바꿉니다.

  8. 눈금자를 끌거나 ▶ 버튼을 눌러 미리 봅니다. Play 모드에 들어갈 필요가 없습니다.

  9. 상태 인스펙터에서 Play On을 PointerEnter로 설정합니다.

  10. 같은 방법으로 Unhover 상태를 만듭니다. 끝 키는 1과 원래 색으로 되돌리고, Play On은 PointerExit로 설정합니다.

  11. Play 모드에 들어가 버튼 위에 포인터를 올렸다가 뺍니다.

전체 과정은 Button Hover Editor 영상에서 볼 수 있습니다. 에디터의 자세한 사용법은 Guide를 참고하세요.

2. 코드에서 재생하기

스크립트에서 상태를 재생하려면 KeyTween 컴포넌트를 참조하고 상태 이름으로 호출합니다. 아래 팝업은 열릴 때 Open을 재생하고, Close가 끝나면 자신을 파괴합니다.

using System;
using KeyTweening;
using UnityEngine;

public class Popup : MonoBehaviour
{
    [SerializeField] KeyTween anim;

    public async Awaitable Open() => await anim.PlayAsync("Open");

    public async Awaitable Close()
    {
        try { await anim.PlayAsync("Close", cancellationToken: destroyCancellationToken); }
        catch (OperationCanceledException) { return; }   // 닫는 도중 다시 열렸으면 팝업을 그대로 둠
        Destroy(gameObject);
    }
}

에디터와 코드는 다음과 같이 역할을 나눕니다.

  • 에디터는 애니메이션 자체를 정합니다. 시간, 이징, 움직일 속성이 여기에 속합니다.
  • 코드는 어느 상태를 재생할지와 끝난 뒤 무엇을 할지만 정합니다.

자세한 내용은 API를 참고하세요.
