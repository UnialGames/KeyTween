설치

KeyTween을 프로젝트에 설치하는 방법을 설명합니다.

요구 사항

  • Unity 6000.0 이상
  • 함께 설치되는 패키지
    • com.unity.ugui 2.0.0 (TextMeshPro 포함)
    • com.unity.mathematics 1.3.2
    • com.unity.burst 1.8.25

Package Manager로 설치 (권장)

Package Manager에서 Git 주소로 설치합니다.

  1. Window > Package Manager를 엽니다.
  2. + 버튼을 누르고 Add package from git URL... 항목을 고릅니다.
  3. 다음 주소를 입력합니다.
https://github.com/UnialGames/KeyTween.git

Packages/manifest.json의 dependencies에 직접 추가할 수도 있습니다.

{
  "dependencies": {
    "com.unialgames.keytween": "https://github.com/UnialGames/KeyTween.git"
  }
}

업데이트

위 주소는 항상 최신 릴리스를 가리킵니다. 새 버전이 나오면 Package Manager에서 KeyTween을 고르고 Update를 누릅니다.

특정 버전으로 설치하기

주소 뒤에 #과 버전 태그를 붙이면 그 버전에 고정됩니다. 버전 목록은 Releases에 있습니다.

https://github.com/UnialGames/KeyTween.git#v0.3.0
  • 고정한 버전은 Update를 눌러도 바뀌지 않습니다.
  • 버전을 바꾸려면 Packages/manifest.json의 태그를 고칩니다.
  • 최신 릴리스를 다시 따라가려면 주소에서 #v…를 지웁니다.

샘플 가져오기

  1. Package Manager에서 KeyTween을 고릅니다.
  2. Samples 탭에서 원하는 샘플의 Import를 누릅니다.

샘플은 프로젝트 안으로 복사됩니다. 패키지를 업데이트한 뒤에는 샘플을 다시 Import해야 새 버전이 반영됩니다.
