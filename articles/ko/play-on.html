Play On

Play On은 상태가 코드 없이 저절로 재생되는 시점입니다.

Play On 고르기

  1. 상태 탭을 골라 상태 인스펙터를 엽니다.
  2. Play On 목록에서 이벤트를 고릅니다.

이벤트를 고르면 KeyTweenTrigger 컴포넌트가 자동으로 붙습니다.

재생되는 때

Play On 재생되는 때
None 자동으로 재생하지 않습니다. 코드에서 Play나 PlayAsync로 재생합니다
OnEnable 컴포넌트가 켜질 때
Start 처음 켜진 뒤 한 번
PointerEnter / PointerExit / PointerDown / PointerUp / Click 해당 포인터 이벤트가 일어날 때
Select / Deselect 해당 선택 이벤트가 일어날 때
ToggleOn / ToggleOff 같은 오브젝트에 있는 Toggle의 값이 바뀔 때

코드에서 재생하는 방법은 API를 참고하세요.

예: 호버하는 버튼

마우스를 올리면 커지고 내리면 돌아오는 버튼은 상태 둘로 만듭니다.

  1. Hover 상태: Scale 트랙을 1 → 1.08로 두고 Play On을 PointerEnter로 고릅니다.
  2. Unhover 상태: Scale 트랙을 1.08 → 1로 두고 Play On을 PointerExit로 고릅니다.
  3. 두 트랙의 Start를 Current Value로 둡니다. 그래야 커지는 도중에 마우스가 나가도 그 자리에서 돌아옵니다.

코드 없이 끝납니다. 재생 시점이 게임 흐름에 달려 있으면(점수가 바뀌었을 때, 화면이 열릴 때) Play On을 None으로 두고 코드에서 재생합니다.

주의할 점

  • 같은 순간에 재생되는 상태가 둘 있으면 경고가 나옵니다. 예를 들어 OnEnable과 Start는 Instantiate할 때 둘 다 호출됩니다.
  • interactable이 꺼진 Selectable은 입력 이벤트를 무시합니다. 이때도 OnEnable과 Start는 재생됩니다.
  • 포인터 이벤트는 EventSystem이 보내 줍니다. UI가 아닌 오브젝트(SpriteRenderer, 3D)에서 받으려면 카메라에 Physics2DRaycaster나 PhysicsRaycaster를, 오브젝트에 Collider를 붙여야 합니다.

UnityEvent에서 재생하기

Button의 OnClick 같은 UnityEvent에서도 상태를 재생할 수 있습니다.

  1. 함수 목록에서 KeyTween.Play (string)을 고릅니다.
  2. 상태 이름을 적습니다.

역재생하려면 PlayReversed (string)을 고릅니다.
