자주 묻는 질문

처음 쓸 때 자주 나오는 질문, 잘 안 될 때 확인할 것, 다른 도구에서 옮겨 올 때의 대응, 버전과 지원 범위를 모았습니다.

Unity 2022 LTS에서 쓸 수 있나요?

쓸 수 없습니다. Unity 6(6000.0) 이상이 필요합니다. 이유는 버전과 지원 범위에 있습니다.

UI Toolkit에서도 쓸 수 있나요?

KeyTween은 uGUI(Canvas)용입니다. UI Toolkit 요소를 움직이는 트랙은 없습니다. UI가 아닌 오브젝트는 움직일 수 있습니다. Transform, SpriteRenderer, 재질 속성, Light, Camera, AudioSource 트랙이 있고, 다른 컴포넌트는 커스텀 트랙으로 더합니다.

DOTween이나 LitMotion과 함께 써도 되나요?

됩니다. KeyTween은 다른 트윈 라이브러리에 의존하지 않고, 서로 영향을 주지 않습니다. 다만 같은 오브젝트의 같은 속성을 두 쪽에서 동시에 움직이면 프레임마다 나중에 쓴 값이 보입니다. 한 속성은 한 쪽에서만 움직이세요.

애니메이션은 어디에 저장되나요?

Prefab(또는 씬 오브젝트)의 KeyTween 컴포넌트 안에 저장됩니다. 클립이나 컨트롤러 같은 별도 에셋은 없습니다. 버전 관리에서는 그 Prefab 파일의 변경으로 보입니다.

코드를 쓰지 않고도 쓸 수 있나요?

상태마다 Play On에서 재생 시점(포인터 진입, 클릭, 켜질 때 등)을 고르면 코드 없이 재생됩니다. Button의 OnClick 같은 UnityEvent에서 KeyTween.Play (string)을 고르는 방법도 있습니다.

상태 이름을 문자열로 쓰는데, 오타가 나면 어떻게 되나요?

없는 이름을 재생하면 콘솔에 경고([KeyTween] '오브젝트' has no state '이름'.)가 남고, PlayAsync는 바로 완료됩니다. 이름을 여러 곳에서 쓴다면 상수로 두는 편이 안전합니다. 상태가 있는지는 anim.HasState("이름")으로 확인합니다.

게임을 일시 정지(timeScale 0)하면 UI 연출도 멈춥니다.

기본값이 게임 시간을 따르기 때문입니다. 일시 정지 메뉴처럼 멈춘 동안에도 움직여야 하는 UI는 그 KeyTween의 Time을 Unscaled로 바꿉니다.

어떤 플랫폼에서 확인했나요?

개발, 테스트, 성능 측정은 Windows(에디터와 IL2CPP 플레이어)에서 했습니다. 다른 플랫폼에서는 확인하지 않았습니다. 플랫폼별 코드는 없고, 이징 계산에 Burst를 씁니다.

샘플을 가져오려면 무엇이 필요한가요?

Input System 패키지가 필요합니다. TextMeshPro의 Essential Resources는 프로젝트에 없으면 샘플을 가져올 때 함께 가져옵니다.

재생 중에 오브젝트가 파괴되면 어떻게 되나요?

  • 트랙이 움직이던 오브젝트가 파괴되면 그 트랙만 건너뜁니다. 나머지 트랙은 끝까지 재생되고 PlayAsync도 정상으로 끝나며, 오류는 나지 않습니다.
  • KeyTween이 붙은 오브젝트가 파괴되거나 꺼지면 재생이 멈추고 PlayAsync는 OperationCanceledException으로 끝납니다. 오류 로그는 남지 않습니다.

버전 관리에서는 어떻게 보이나요? 머지 충돌은요?

애니메이션은 별도 파일 없이 Prefab(또는 씬) 파일 안의 KeyTween 컴포넌트에 들어 있습니다. 상태를 고치면 그 Prefab 파일이 바뀌고, 버전 관리에서는 다른 Prefab 변경과 똑같이 보입니다.

  • 두 사람이 같은 Prefab의 상태를 동시에 고치면 일반 Prefab 충돌과 같습니다. Unity의 Smart Merge(UnityYAMLMerge)를 쓰거나 한 사람씩 고칩니다.
  • 화면과 부품을 Prefab으로 나눠 두면 충돌하는 범위가 줄어듭니다. 바깥 Prefab에서 고친 자식의 연출은 바깥 Prefab 파일에 저장됩니다.
  • Auto Save가 켜져 있으면 마지막 편집 0.4초 뒤에 Prefab 파일에 저장됩니다. 창에서 시험 삼아 고친 것도 파일에 남으므로, 커밋하기 전에 변경 내용을 확인합니다.

나중에 KeyTween을 빼려면 어떻게 하나요?

  1. 코드에서 KeyTweening 네임스페이스를 쓰는 곳을 다른 방식으로 바꿉니다.
  2. Prefab과 씬에서 KeyTween, KeyTweenTrigger 같은 KeyTween 컴포넌트를 지웁니다. 패키지를 먼저 지우면 이 컴포넌트들이 Missing Script로 남습니다.
  3. Package Manager에서 패키지를 지웁니다.

애니메이션을 Animator 클립이나 다른 도구의 형식으로 내보내는 기능은 없습니다. 데이터는 컴포넌트와 함께 사라집니다.
