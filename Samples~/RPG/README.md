# RPG

모바일 판타지 RPG의 타이틀·로비와 거기서 열리는 화면들을 KeyTween으로 만든 샘플입니다.
화면의 움직임은 모두 각 Prefab의 **KeyTween 상태**이고, 스크립트는 화면을 열고 닫고 데이터를 채우기만 합니다. 상태는 KeyTween 창에서 열어 고칠 수 있습니다.

- 장면: `Scenes/RPG.unity` (1920×1080 기준). Play를 누르면 타이틀부터 시작합니다.
- 필요: **Input System** 패키지(장면의 EventSystem이 `InputSystemUIInputModule`, 포인터 하나만 받도록 `SingleUnifiedPointer`로 두 버튼 동시 누름을 막음), TextMeshPro(uGUI 2.x에 포함)
- 스크립트(`Scripts/`)에는 asmdef가 없어 프로젝트의 기본 어셈블리로 컴파일됩니다. 진입점은 `RpgDemo`(페이지 컨테이너 + 모달 컨테이너)입니다.

## 화면

**페이지** (`KeyTweenPageContainer`, 뒤로 가기로 돌아옴)

| 화면 | 보여 주는 것 |
|---|---|
| 타이틀 · 로딩 | 로고 글자 낙하, TAP TO START 깜빡임(반복). 로딩 막대 채우기와 %가 막대 값을 따라감, 룬 회전. 둘 다 `stack: false`라 기록에 남지 않음 |
| 로비 | 패널·재화·영웅·메뉴가 차례로 들어오는 등장, 영웅 숨쉬기(상태 Loop + Play On: OnEnable, 코드 없음), 이벤트 배너(루프 + 한 장씩 + 자동 넘김 + 점), 알림 배지(우편 개수·출석·퀘스트, 같은 모양으로 맥박) |
| 영웅 · 상세 | 그리드 순차 등장, 정렬을 바꾸면 다시 등장, 카드 초상이 상세 화면 자리로 이어지는 **공유 요소**, 상세 목록(줄 등장·능력치 바), 스크롤하면 접히는 제목 영역(`KeyTweenScrollScrub`) |
| 강화 | UPGRADE → 섬광·레벨 Punch·능력치 색(골드가 모자라면 버튼 흔들림), AUTO EQUIP → 장비가 칸에 차례로, 전투력 숫자 세기(Number 트랙, 끝 값만 코드가 `SetEndValue`) |
| 가방 | 탭 + 한 장씩 넘기는 페이지(안에 그리드, 중첩 스크롤), 슬롯 아이콘이 정보 팝업으로 이어지는 공유 요소, USE → 수량 휠 → 토스트 |
| 소환 | 회전하는 마법진, x1 / x10(x10은 5★ 1장 이상 보장, 젬이 모자라면 흔들림), 결과 팝업 |
| 모험 · 편성 · 전투 | 챕터 캐러셀, 스테이지 순차 등장과 다음 스테이지 맥박, 편성(영웅 넣기 `In` / 빼기는 같은 상태 역재생, 전투력 세기), BATTLE → 돌진·섬광 → 전투(적 피격, 피해 숫자, 스킬 재사용 대기 Fill, 체력 막대) |
| 퀘스트 | 고정되는 섹션 헤더(Sticky Header), 받기 → 도장 → 재화 세기 → 그 줄이 접혀 사라짐(`await ResizeItem`) |
| 상점 | 특가 배너 빛·남은 시간, 상품 그리드(남은 수량 배지), 구매 후 품절 도장 |
| 우편 | 받기 → 보상이 떠오르고 줄이 접힘, 모두 받기 → 함께 사라짐(옵션으로 한 통씩), 비면 안내 |
| 길드 채팅 | 글 길이만큼 폭·높이가 정해지는 말풍선(Measure Items, Stick To End), 입력창·SEND, 입력 중 점 세 개 |
| 랭킹 | 단상 상승·초상 낙하·왕관, MY RANK → 그 줄로 스크롤·강조 |
| 스토리 | 화자 등장(다른 쪽은 작아짐), 타자기(탭하면 `Complete`), 선택지 |

**팝업** (`KeyTweenModalContainer`): 아이템 정보, 수량(휠 피커), 소환 결과(섬광 → 카드 낙하 → 한 장씩 뒤집기, 4★ 빛, 5★ 흔들림·빛줄기), 승리(글자·별·보상·경험치), 패배(붉은 화면·해골·팁 타자기), 구매(가격이 모자라면 흔들림), 출석(7일 칸, 오늘 칸 반짝임, 받기 → 도장), 설정(스위치, 볼륨 슬라이더, 초기화), 확인

**토스트**: 별도 캔버스, 여러 개가 오면 차례로
