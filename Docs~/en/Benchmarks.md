## Environment

- A Windows 64-bit player built with Unity 6000.6.3f1, run 1280×720 windowed with VSync off.
- The CPU is an AMD Ryzen 7 7800X3D 8-Core Processor.
- Each case runs a 1 s warm-up followed by 4 s of measurement. The values come from a single run, so they can vary by about ±5 %.
