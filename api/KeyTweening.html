Classes

KeyTween

Holds the animation states of one prefab and plays them. States can run at the same time; a newly played state takes over only the properties it animates.

KeyTweenBinding
KeyTweenChildCall

Plays another KeyTween's state at a point in this state's time (e.g. a popup showing its buttons).

KeyTweenColorTrack<T>

A custom track of a Color.

KeyTweenCustomTrack<T>

A custom track on a component of type T. Override Get(T) and Set(T, Vector4); the value is a Vector4 (use x for one number, x/y for two …) as Kind says.

[Preserve] public sealed class SliderHandleTrack : KeyTweenCustomTrack<Slider> { … }

The class needs a public parameterless constructor. Mark it [UnityEngine.Scripting.Preserve] when the build strips code (IL2CPP with Managed Stripping Level above Minimal), because tracks are created from the saved class name.

KeyTweenDefaultTransitions

Default transitions, the same as UnityScreenNavigator's defaults: 0.3 s OutQuart. Pages slide by one screen width (Size Relative, so any resolution), modals grow from 0.3 and fade in, backdrops and sheets fade (Linear).

KeyTweenEasing

The easing formulas (easings.net, as in LitMotion's EaseUtility).

KeyTweenEventAttribute

Registers a struct as a custom animation event type. Its public fields become the event's parameters, edited per event in the KeyTween Editor; code receives them with anim.AddListener((in KeyTweenEventInfo e, in HitEvent hit) => ...).

[KeyTweenEvent("Hit")] public struct HitEvent { public float damage; public string sfx; }

Fields: numbers, bool, string, Vector2/3, Color, enums (stored as JSON, so no object references).

KeyTweenEventListener

Connects animation events to UnityEvents in the Inspector, so designers can react without code (e.g. "Shown" → AudioSource.PlayOneShot). Custom [KeyTweenEvent] struct data is for code: use KeyTween.AddListener<T>.

KeyTweenEventListener.Binding
KeyTweenEventMarker

An animation event: a named point in a state's time, raised once when playback passes it (e.g. play a sound on impact). It can carry one custom KeyTweenEventAttribute struct, stored as JSON and converted once on first use.

KeyTweenEventTrack

A track of animation events (added like any other track).

KeyTweenExternalProperties

Track properties of components from optional packages (UIEffect …). The core lists them in KeyTweenProperty but does not reference those packages: each package's integration assembly (compiled only when the package is installed) registers how to read and write its properties. Unregistered ones (package not installed) are skipped.

KeyTweenExternalProperties.Entry
KeyTweenFloatTrack<T>

A custom track of one number. e.g. class SliderValueTrack : KeyTweenFloatTrack<Slider>.

KeyTweenKey

A value at a time. Ease/curve describe how the track arrives at this key from the previous one.

KeyTweenModalContainer

Modals on top of each other. Each has its own backdrop (a dimmed full-screen image) that fades with it; the modal under the new one does not move.

KeyTweenOverride

A nested KeyTween's state changed inside this prefab only (e.g. the common button flashes differently in this popup). Only the changed tracks are stored, matched to the child's by target + property; every other track keeps following the child's own state, so later changes to the child prefab still show up here. Stored on the outer prefab, so the child's prefab is never touched; for the same track the outermost override wins.

KeyTweenPageContainer

A history of pages: Push puts a page on top (the old one leaves at the same time), Pop goes back. A page pushed with stack = false is dropped from the history once the next page is in (e.g. a loading page).

KeyTweenPageIndicator

Dots or tabs for a scroll list's items (pages, banners, tab pages): one item per list item, laid out by this object's layout group. The current one plays the On state and the one it replaces plays Off. Clicking one scrolls there.

KeyTweenPlay

A play of one state, set up in code before it starts (With(string)): a track's end value or arrival, where it starts, callbacks. Nothing changes until it plays; the changes hold for that play only (put back when it completes or is canceled), and the same object can be played again and again, like a LitMotion builder you keep.

KeyTweenPullToRefresh

Pull to refresh on a list: pulling past the start shows the Pull state by distance; releasing past Distance raises On Refresh and plays the Refreshing state (repeated) until EndRefresh(), holding the list open meanwhile. For vertical lists (pulled down from the top).

KeyTweenScreen

A page, modal or sheet shown by a screen container. Its transitions are states of its KeyTween, by name: pages "PushEnter", "PushExit", "PopEnter", "PopExit"; modals "Enter", "Exit"; sheets "Enter", "Exit" (and optionally "EnterBackward", "ExitBackward"). A missing one uses the container's default.

KeyTweenScreenContainer

Shared by the page, modal and sheet containers: taps are off on every container while any of them is in a transition (so a second tap cannot start another one), and screens get their default transitions from here.

KeyTweenScrollList

A virtualized list on a ScrollRect: only the visible items exist, and they are reused as the list scrolls. Laid out like Unity's Vertical / Horizontal / Grid Layout Group (plus Masonry), filled through callbacks like UI Toolkit's ListView (bind / unbind by index), and animated with the items' KeyTween states: an entry stagger, a state when scrolling brings an item into view, and a state scrubbed by the item's position. Also: several item prefabs, variable sizes, infinite loop, snapping / one page per swipe, auto scroll, sticky section headers, sticking to the end (chat), animated item resizing (accordion) and nested scrolling.

KeyTweenScrollScrub

Shows a state by how far a list is scrolled instead of by time: 0 px = the state's start, Distance = its end (a header that collapses as the list scrolls, a toolbar that fades in).

KeyTweenSharedElement

Shared element transitions: an image on one screen appears to travel to (or from) where it sits on another screen. The motion is a normal state (AnchoredPosition + SizeDelta tracks on the moving image, edited in the window); only the other screen's end is known at run time, so this writes it into the state's first or last keys just before the state plays.

KeyTweenSheetContainer

Sheets (tab pages) without history: Show switches to one, the old one leaves at the same time. Moving to a lower index plays "EnterBackward" / "ExitBackward" when the sheet has them (e.g. slide the other way).

KeyTweenSound

A sound played once when playback passes its time, through the KeyTween's AudioSource.

KeyTweenSoundTrack

A track of sounds played through source (empty = the KeyTween's AudioSource).

KeyTweenState
KeyTweenStateBuilder

A state made in code (Build(string)): tracks and keys, events, sounds and callbacks, added to the KeyTween as a runtime state (not saved) and played by name like one made in the editor. Add() adds it; the Play methods add it and play it. Calls after that keep editing the same state.

KeyTweenTrack
KeyTweenTrackType

What a track animates: which component it needs, how to read and write the value, and how the editor shows it. The built-in tracks are instances of this class; a custom track derives from KeyTweenCustomTrack<T> (or KeyTweenFloatTrack<T>, KeyTweenVector2Track<T>, KeyTweenVector3Track<T>, KeyTweenColorTrack<T>) and then appears in the Add Track window for objects that have T.

KeyTweenTrackTypes

Finds the type of a track: built-in by its KeyTweenProperty, custom by its saved class name.

Implement on any component of a screen's root to run code around its transitions. The Will* calls are awaited before the animation starts (load data, preload the next screen); the Did* calls come after it ends.
