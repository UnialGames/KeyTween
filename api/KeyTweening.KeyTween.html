PlayAsync(string, CancellationToken)

Plays a state and completes when it reaches its end (or Complete(string) skips there). Canceled (OperationCanceledException) when the state does not finish: another state took all of its properties, it was played again, the object was disabled, or cancellationToken fired. e.g. await anim.PlayAsync("Close"); Destroy(gameObject); never destroys a popup that was reopened mid-close.

SetEndValue(string, Component, KeyTweenProperty, Vector4)

Sets where a track ends from code, for values known only at runtime: e.g. a "Count" state counting a gold label (Text Number, Start = Current) from what it shows to the new amount. Replaces the last key's value (read the same way, so relative tracks stay relative) on every play from now on. Call before playing the state. For a state played by something else (Play On, a screen transition); when your code plays it, With(string)(state) .WithEndValue(...) sets it for that play only.

Stop(string, float)

Stops the state if it is playing (a pending PlayAsync is canceled) and shows its pose at time (seconds, clamped to 0 to Duration(string)), without playing: no motion, events or sounds. Also for effects driven by something other than time, called every frame, e.g. a scroll list item scaled by its place in the viewport. The live start values (Start = Current) are taken the first time, then reused.
