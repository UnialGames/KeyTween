What a track animates: which component it needs, how to read and write the value, and how the editor shows it. The built-in tracks are instances of this class; a custom track derives from KeyTweenCustomTrack<T> (or KeyTweenFloatTrack<T>, KeyTweenVector2Track<T>, KeyTweenVector3Track<T>, KeyTweenColorTrack<T>) and then appears in the Add Track window for objects that have T.
