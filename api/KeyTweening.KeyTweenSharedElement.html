Shared element transitions: an image on one screen appears to travel to (or from) where it sits on another screen. The motion is a normal state (AnchoredPosition + SizeDelta tracks on the moving image, edited in the window); only the other screen's end is known at run time, so this writes it into the state's first or last keys just before the state plays.
